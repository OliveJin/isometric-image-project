# ✦ The Moment

> 360° 沉浸式全景空间 —— 创造属于你的记忆时刻

## 简介

The Moment 是一款基于 Three.js 的 360° 全景空间浏览器。上传照片即可创建沉浸式全景空间，支持**三层音频系统**和**星尘互动点**，让每个空间成为独一无二的感官体验。

### 核心功能

- **🎨 三种空间创建方式**
  - **本地贴图** (1 张)：直接使用 equirectangular 全景图，无需后端
  - **AI 合成** (4 张)：通过火山引擎 AI 识别场景并生成全景图
  - **OpenCV 拼接** (10+ 张)：自动拼接多张重叠照片为 360° 全景

- **🎵 三层音频系统**
  - **背景音乐 (BGM)**：可选循环音乐，右上角一键开关
  - **方向环境音**：四个方向独立音频，随视角**平滑渐变过渡**
  - **互动触发音**：点击交互点播放一次性音效

- **✨ 星尘互动点**
  - **引导点** (暖金色)：上升闪烁微粒，点击弹出引导问题 + 触发音频
  - **语音点** (青蓝色)：同样星尘格式，点击播放环境音效
  - 中心密集明亮，外圈稀疏渐变

- **⚙️ 球内编辑器**：进入空间后通过 ✦ 按钮打开，分 **🎵 环境音** / **📍 互动点** 两栏管理

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 3D | Three.js 0.128 |
| 前端框架 | Vite 4 + Vanilla JS (ES Modules) |
| 后端 | Spring Boot 3.5 + Java 17 |
| 音频 | Web Audio API (AudioContext) |
| 图像处理 | OpenCV / JavaCV, 火山引擎 ARK AI |

**端口分配：**

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 Vite | `3000` | 主界面 |
| 后端 Spring Boot | `8080` | API、上传、图片代理 |
| OpenCV Python | `5000` | 全景拼接 (可选) |

## 快速开始

### 环境要求

| 依赖 | 版本 |
|------|------|
| Node.js | 18+ |
| JDK | 17+ |
| Maven | 3.8+ |

### 启动

```bash
# 1. 启动后端 (端口 8080)
cd backend
./mvnw spring-boot:run

# 2. 启动前端 (端口 3000)
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`

### 使用流程

1. 点击 **"进入此刻"** → 选择一个空间 → 确认进入
2. 进入全景空间后，点击右下角 **✦** 按钮打开编辑器
3. **🎵 环境音** 标签页：上传 BGM、主环境音、四个方向环境音
4. **📍 互动点** 标签页：创建引导点/语音点 (点击球面放置)，上传触发音频
5. 点击星尘位置可触发音频播放和提示气泡

## 音频系统架构

```
┌──────────────────────────────────────────┐
│              AudioContext                 │
│  ┌─────────┐ ┌───────────┐ ┌──────────┐ │
│  │   BGM   │ │ 主环境音   │ │  触发音   │ │
│  │ (循环)  │ │  (循环)   │ │ (一次性)  │ │
│  └─────────┘ └───────────┘ └──────────┘ │
│  ┌─────────────────────────────────────┐ │
│  │      四方向环境音 (平滑渐变)         │ │
│  │  ⬆ N   ➡ E   ⬇ S   ⬅ W           │ │
│  │  权重 = cos(角度差 / 90° × π/2)    │ │
│  └─────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

方向环境音基于相机朝向实时计算 cos 权重，相邻方向自然叠加，实现无缝渐变过渡。

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/spaces` | 获取所有空间 |
| POST | `/api/spaces` | 创建空间 |
| PUT | `/api/spaces/{id}` | 更新空间 (含音频配置) |
| DELETE | `/api/spaces/{id}` | 删除空间 |
| POST | `/api/upload/audio` | 上传音频文件 |
| POST | `/api/upload` | 上传全景图 (AI 合成) |
| POST | `/api/opencv/upload` | 上传图片 (OpenCV 拼接) |
